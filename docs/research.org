#+title: Design research and decisions

* Sources checked 2026-10-19

- CNCF curriculum PDFs and certification pages define current scope, versions,
  weights and competency boundaries.
- Kubernetes documentation, API references and official examples define
  expected behavior and supported configuration.
- kind v0.33.0 provides the v1.37.0 node image for fast API-level scenarios;
  nodes include systemd, containerd, crictl and static manifests at
  =/etc/kubernetes/manifests=.
- vagrant-libvirt 0.12.2 provides the separate VM backend for node and
  control-plane behavior.
- Kubernetes Gateway API specifications and conformance examples define the
  supported Gateway workflows; Traefik is an explicit pinned component.

* Original challenge research

[[file:research-cka-ckad.org][research-cka-ckad.org]] records public CKA and CKAD
idea sources, concrete challenge themes, licensing boundaries and the
original-content workflow. New labs use public behavior sources but author
fresh task text, fixtures, failure injection, solutions and checks.

* Adopted conventions

Shell setup and validation remain useful for host scripts, but labs use typed
Pydantic metadata and read-only behavioral checks. The evaluator adds
structured actual-vs-expected details.

The platform uses kind for fast API-level work and a separate Vagrant/libvirt
kubeadm backend for node/control-plane realism. It does not pretend one
backend can model both a shared host kernel and an independent VM kernel.

* Deliberate non-goals

- No remote web service or paid-platform dependency.
- No machine-learning recommendation system; weakness is a transparent
  Laplace-smoothed failure rate, with hint use reducing a pass's credit and
  older results weighted less (21-day half-life).
- No actual exam questions or claim of official scoring.
- No hidden controller dependency. Since 2026-10-23, controllers come as
  explicit, pinned cluster components (=requires: [traefik]=, see
  [[file:safety.org][safety]]). Traefik 3.7 serves Ingress and the Gateway API. The Gateway API
  CRDs (v1.6.3, the version in Traefik's =go.mod=) are a separate manifest
  component, which Traefik requires. Traefik binds Gateway listeners to the
  entrypoint with the same port, so listeners use port 8000. Port 80 is
  rejected with =PortUnavailable=.
